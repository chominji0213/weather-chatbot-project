# 날씨/생활정보 챗봇

자연어로 날씨를 물어보면 기상청 공공데이터포털 API를 직접 호출해서 실제 데이터 기반으로 답해주는 챗봇입니다. AI 서비스 포트폴리오의 첫 번째 프로젝트로, "LLM이 외부 API를 스스로 판단해서 호출하는 가장 단순한 구조"를 손으로 직접 구현하는 것이 목표입니다.

## 이 프로젝트로 연습한 것

- **Tool Calling / Function Calling**: LLM이 사용자 질문을 보고 도구(함수) 호출이 필요한지 스스로 판단하고, 실제로 호출한 뒤 결과를 받아 자연어 답변을 생성하는 흐름
- **LangChain 기반 에이전트 구성**: `init_chat_model` + `create_agent`로 모델과 도구를 연결
- **멀티턴 대화 메모리**: LangGraph 체크포인터(`MemorySaver`)와 `thread_id`를 이용해 이전 대화 맥락을 기억하는 구조
- **공공 데이터 API 연동**: 기상청 공공데이터포털 단기예보 API 호출, 위경도 → 격자좌표 변환, 발표 시각 스케줄링 로직
- **Streamlit 채팅 UI**: `session_state`를 이용한 세션별 상태(에이전트, 대화 기록, thread_id) 관리

## 기술 스택

- LLM: Gemini 3.1 Flash-Lite (Google AI Studio API)
- LLM 오케스트레이션: LangChain, LangGraph(체크포인터)
- 날씨 데이터: 기상청 공공데이터포털 단기예보 조회서비스
- 웹 UI: Streamlit
- 언어: Python 3.11+

## 실행 방법

1. 이 저장소를 클론하고 가상환경을 만듭니다.

   ```
   python -m venv .venv
   .venv\Scripts\activate
   ```

2. 패키지를 설치합니다.

   ```
   pip install -r requirements.txt
   ```

3. `.env.example`을 참고해서 `.env` 파일을 직접 만들고 API 키를 채웁니다.

   ```
   GOOGLE_API_KEY=your_gemini_api_key
   KMA_API_KEY=your_kma_decoding_key
   ```

4. 앱을 실행합니다.

   ```
   streamlit run app.py
   ```

## 실행 예시

```
사용자: 오늘 서울날씨 어때?
챗봇: 오늘 서울은 흐린 날씨를 보이고 있습니다. 현재 기온은 28도이며, 습도가 80%로 다소 높은 편입니다.
      강수 확률은 30%로 비가 올 가능성은 낮아 보입니다. 외출 시 참고하세요!

사용자: 우산 챙기면 되는건가?
챗봇: 현재 서울의 강수 확률이 30%로 낮고 강수 형태도 없어서 당장 비가 쏟아질 가능성은 작아 보입니다.
      하지만 습도가 높고 흐린 날씨가 이어지고 있으니, 혹시 모를 상황에 대비해 가벼운 우산을 챙기시는
      것도 나쁘지 않을 것 같습니다.
```

두 번째 질문에서 도시를 다시 언급하지 않아도 이전 대화 맥락(서울)을 기억해서 답합니다.
